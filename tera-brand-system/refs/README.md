# Refs da Téra — galeria 3D + links

**Galeria:** `refs/galeria-refs.html` — arquivo único, autocontido (three.js + imagens + fontes inline, ~1.8 MB). Abre por duplo clique ou via `python scripts/serve_case.py` → `http://localhost:8123/refs/galeria-refs.html`. Arrastar/rolar navega, clique abre a ref com links, botão ÍNDICE lista tudo.

Fontes das refs: `TERA_BRAND.md`, `brand/04_IDENTIDADE_BRIEF.md`, `brand/02_ESTRATEGIA.md`, `brand/03_POSICIONAMENTO.md`.
